# Pattern World expansion roadmap

The current release establishes the complete product structure: three connected learning tracks,
43 concept guides, four interactive visualizations, and the original 83-pattern foundation.

The long-term goal is broad coverage without turning the site into a wall of notes. Every new topic
should earn its place through a clear mental model, a small visual, useful pseudocode, and simple
Python where code helps.

## Release 2 — Complete the algorithm lab

- Add selection, insertion, merge, quick, and heap sort visualizations.
- Add array, linked-list, stack, queue, hash-map, heap, and trie operation labs.
- Add recursion-tree and backtracking decision-tree views.
- Add tree traversal, topological sort, Dijkstra, union-find, and minimum-spanning-tree labs.
- Add two-pointers, sliding-window, prefix-sum, monotonic-stack, interval, and top-K pattern views.
- Add 1D, grid, knapsack, subsequence, interval, and tree dynamic-programming families.
- Add a Big O comparison view that connects input growth to practical cost.

## Release 3 — Python and low-level design studio

- Add visual relationship diagrams for association, aggregation, composition, and dependency.
- Add one focused guide for every major creational, structural, and behavioral design pattern.
- Add state-transition and sequence views alongside the class view.
- Add Python-specific guides for dataclasses, properties, protocols, abstract base classes,
  iterators, context managers, decorators, exceptions, and typing.
- Add concurrency visuals for race conditions, locks, semaphores, deadlocks, producer-consumer, and
  worker pools.
- Add progressive case studies: parking lot, vending machine, elevator, library, split expenses,
  ticket booking, and ride sharing.
- Show how each case study evolves when one requirement changes.

## Release 4 — System design walkthroughs

- Add interactive request journeys for DNS, TLS, reverse proxies, and service discovery.
- Add load-balancing policy comparisons and failure simulation.
- Add rate-limiter visualizations for token bucket, leaky bucket, fixed window, and sliding window.
- Add index, cache, replication, partitioning, and consistent-hashing visualizations.
- Add queue delivery, retry, dead-letter, event-ordering, and idempotency views.
- Add consistency and quorum tradeoff simulators.
- Add reliability views for timeouts, backoff, circuit breakers, failover, and graceful degradation.
- Add complete design walkthroughs for URL shortening, autocomplete, notifications, chat, social
  feeds, file storage, video streaming, payments, job scheduling, and analytics.
- Add capacity-estimation worksheets with adjustable inputs.

## Release 5 — Learning quality

- Add optional browser-local progress and bookmarks without requiring an account.
- Add “explain it back” prompts and quick self-checks to each concept.
- Add glossary linking across all three tracks.
- Add keyboard shortcuts and reduced-motion alternatives for every lab.
- Add print-friendly study sheets.
- Add automated accessibility, link, and content-schema checks.
- Add contributor templates and editorial guidelines so new guides stay simple and consistent.

## Definition of done for a new guide

Every guide should include:

1. One-sentence purpose.
2. A simple intuition without unnecessary jargon.
3. Three recognition or decision cues.
4. Plain-language pseudocode.
5. The smallest useful Python example, when code applies.
6. Complexity or system tradeoffs.
7. Links to the concepts immediately before and after it.
8. A visual only when it improves understanding.
