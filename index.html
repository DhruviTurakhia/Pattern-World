Why this project exists

A university exercise, turned into one complete learning resource.

01

Build loop intuition

Pattern programs make iteration visible. Each line of output shows how row and column conditions affect a result.

02

Compare approaches

The collection moves from direct repetition to nested loops, spacing logic, numeric sequences, and conditional output.

03

Keep the original work useful

Two early repositories are now combined into one responsive website and one organized Python source library.

Project context

Created by Dhruvi Turakhia

Pattern World began as a university curriculum project in 2021. The original Python exercises are preserved, while the web experience and repository structure have been rebuilt to make the collection easier to browse, understand, and share.
